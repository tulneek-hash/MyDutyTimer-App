Политика конфиденциальности

My Duty Timer — мобильное приложение для контроля дежурных смен.

1. Какие данные мы собираем

Приложение не собирает персональные данные пользователей. Мы не запрашиваем имя, email, телефон, местоположение или другие идентифицирующие данные.

2. Локальное хранение

Все данные (профили смен, настройки, журнал событий) хранятся только на устройстве пользователя и не передаются на серверы разработчика.

3. Разрешения

Приложение запрашивает следующие разрешения:

• Уведомления — для доставки оповещений о событиях смены

• Работа в фоне — для корректного срабатывания таймеров при выключенном экране

• Точные будильники — для своевременной доставки уведомлений

• Вибрация — для вибросигналов

• Автозапуск — для восстановления смены после перезагрузки устройства

4. Реклама

Приложение показывает рекламу через сервис Яндекс.Мобайл. Рекламная сеть может собирать обезличенные данные (тип устройства, версия ОС, идентификатор рекламы) для показа релевантной рекламы. Подробнее: Политика Яндекса.

5. Передача данных третьим лицам

Мы не продаём и не передаём данные пользователей третьим лицам, за исключением случаев, предусмотренных законодательством.

6. Контакты
